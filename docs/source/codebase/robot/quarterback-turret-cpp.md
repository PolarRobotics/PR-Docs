## Quarterback Turret
### Firing Controls
```{warning}
Do not fire unless moving forward (do not fire when intaking or stopped)
```
#### Automatic Controls
| Control | Description |
| :-----: | :---------: |
| Options | Switch between manual and automatic control |
| L1 | Switch Target to Reciever 1 |
| R1 | Switch Target to Reciver 2 |

#### Manual Controls
| Control | Description |
| :-----: | :---------: |
| Options | Switch between manual and automatic control |
| Right Stick X | Control the turret direction (Left is CCW, Right is CW) |
| Left Stick Y | Flywheel Override |
| D-Pad Up | Increase flywheel speed by one stage |
| D-Pad Down | Decrease flywheel speed by one stage |

### General Controls

| Control | Description |
| :-----: | :---------: |
| Touchpad | Emergency Stop |
| Square | Toggle Flywheels & the Turret on and off |
| Circle | Startup and Home (Reset or Zero Turret) |
